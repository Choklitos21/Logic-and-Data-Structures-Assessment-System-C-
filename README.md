# Logic and Data Structures Assessment System

A C# console application for practicing and assessing logic and data structures concepts.

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) 6.0 or higher

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo.git
   ```

2. Navigate to the project folder:
   ```bash
   cd "Logic and Data Structures Assessment System"
   ```

3. Run the application:
   ```bash
   dotnet run
   ```
